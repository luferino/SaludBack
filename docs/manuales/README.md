## El recorrido en una línea

**Administración habilita las cuentas y los períodos → Recepción, en Pacientes y Disponibilidad, registra o vincula al paciente y habilita disponibilidad → un rol autorizado crea la asignación en Académico → Asignaciones de pacientes → el estudiante registra la atención → el docente revisa las etapas que le corresponden.**

- **Vincular** incorpora al paciente a una carrera sin crear otra ficha.
- **Habilitar disponibilidad** permite considerarlo para una materia y grupo; no lo asigna. Retirarla no finaliza una asignación activa.
- **Crear una asignación** vincula al paciente con un estudiante habilitado en el contexto; no significa que ya fue atendido.
- **Guardar un borrador**, **enviar**, **validar** y **aprobar un procedimiento** son acciones distintas. Lo que se puede consultar depende del módulo, rol y contexto.

Estas guías explican el uso del sistema, no cómo realizar un procedimiento clínico. Usá datos ficticios para practicar y no compartas contraseñas, capturas ni datos de pacientes por canales no autorizados.
